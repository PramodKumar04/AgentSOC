# Target 2 — SSE results on LANL data

> **Real, sampled LANL 2015 data** (one contiguous 400,000-line window). This shows how the SSE behaves on real logs. It does not measure detection accuracy, and a connected path is not evidence of compromise. Synthetic results are in a separate file, [target2_synthetic_results.md](target2_synthetic_results.md).

Generated by `python scripts/evaluate_structure.py lanl`. Engine `sse/1.0`, detection engine `auth-detect/1.1`. Validated against observed logons only; LANL has no topology, so `INFEASIBLE` means not observed.

The half-window run uses a 1,027 s baseline, far too short to represent normal behaviour, so its novelty-based incidents are expected to be dominated by benign activity. Inferred paths join different accounts by assumption.
