# Target 1 — LANL sensitivity results

> **Real, sampled LANL 2015 data** (one contiguous 400,000-line window). A sensitivity check of how the rules behave, not a measure of detection accuracy. Synthetic results are in a separate file, [target1_synthetic_results.md](target1_synthetic_results.md).

Generated by `python scripts/evaluate_lateral.py lanl`. Engine `auth-detect/1.1`. Outputs are in `data/processed/lanl_validation_target1`; the stored Phase 2 outputs are read only.

The default 2-day baseline needs about 33.3M lines and does not fit in memory here, so under default settings the novelty-based rules have nothing to evaluate. The half-window run uses a baseline of 1,027 s, far too short to represent normal behaviour; its novelty findings are expected to be dominated by benign activity.
